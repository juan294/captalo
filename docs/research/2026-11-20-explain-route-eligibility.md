## Exact services, data and cost

**OpenAI.** The catalog lists `gpt-6.1-terra`, streamed Responses and `reasoning.effort: none`. The snapshot section lists the same identifier. The free API tier lacks access. Standard text pricing is $1 per million uncached input tokens and $5 per million output tokens. Implicit 30-minute cache writes can cost $1.25 per million input tokens. Cached reads cost $0.05 per million. A bound for an ordinary request must account for cache writes and the response token ceiling. Regional processing and other service tiers have distinct rates. [Model, tiers and pricing](https://developers.openai.com/api/docs/models/gpt-6.1-terra) · [Cache options and default behavior](https://developers.openai.com/api/docs/guides/prompt-caching)

Explain would send source text, listener settings and any supplied profile in one text-only foreground request with `store: false`. This turns off the normal stored response. Standard abuse-monitoring logs may contain inputs and outputs for up to 30 days, or longer for legal or safety reasons. Prompt caching may retain encrypted model state on the provider’s GPU machines for up to 24 hours. API data can be used for training when the customer opts in. Zero Data Retention (ZDR) requires provider approval, an applicable organization or project configuration and an eligible service. A request flag, a paid tier or a successful answer cannot establish ZDR. [Responses data controls and exceptions](https://developers.openai.com/api/docs/guides/your-data)

**Anthropic.** The direct Claude Messages model is `claude-sonnet-5-5`. Its assessed configuration uses `thinking.type: between_tools` and low effort. The listed base rates are $2 per million input tokens and $10 per million output tokens. The assessed plain Messages request does not ask for cache writes, tools or batch execution. Organization and workspace limits vary. An organization’s monthly budget is a different limit from the spend authorized for an individual test run. [Sonnet 5.5 specifications](https://platform.claude.com/docs/en/models/sonnet-5-5/overview) · [Rate and spend limits](https://platform.claude.com/docs/en/api/rate-limits)

Under standard commercial API terms, Anthropic normally deletes inputs and outputs within 30 days. Contracts, use of other services, law and enforcement can change retention. When safety systems flag a policy violation, inputs/outputs may remain for up to two years and classification scores for up to seven. The commercial terms prohibit model training on customer content under that agreement. Sonnet 5.5 is absent from the published list of Covered Models requiring 30-day retention. Plain Messages is ZDR-eligible under an applicable arrangement. Workspace settings and the actual agreement still govern. [Commercial Terms, §B](https://www.anthropic.com/legal/commercial-terms) · [API retention and exceptions](https://privacy.claude.com/en/articles/7996866-how-long-do-you-store-my-organization-s-data) · [Model and feature eligibility](https://platform.claude.com/docs/en/manage-claude/api-and-data-retention)
