# Read in my own voice

An English-speaking user can choose **My own voice**, record the supplied passage, hear a different sentence in their voice and decide whether to use it. Their next selection or screen region uses that voice. Built-in voices continue to work with the original installation. The feature requires Apple Silicon and an explicit model download. The recording never leaves the Mac. [Accepted design brief](../research/2026-11-14-own-voice-brief.md)

## Engineering choices

Use the accepted 4-bit Qwen3-TTS 1.7B Base model. A lazily launched arm64 helper isolates the native MLX dependencies from the universal menu-bar app. The helper adds installed bytes even for people who use only built-in voices. Measure that increment separately from the opt-in weights. Linking MLX directly into the main executable would couple startup and Intel builds to the optional engine. Shipping the shaders with the helper lets the end user run it without installing developer tools. The [native feasibility record](../research/2026-11-22-own-voice-native-feasibility.md) distinguishes the standalone probe from the signed app milestone.

Keep a built-in voice ID and a separate personal-voice selection. Store the public model once and keep the accepted personal recording and its transcript in a separate private directory. Reuse the existing sentence splitter, timing and playback owner. A text-only language model, cloud service, account or speech-recognition download is unnecessary for setup. The known recording prompt supplies the transcript.

## Stuck states and recovery

| What the user sees | Recovery and proof |
| --- | --- |
| Own Voice unavailable on Intel | Explain Apple Silicon availability in Voice. Launch the universal reader and exercise a built-in voice. Check Intel launch on available Intel hardware separately from binary inspection. |
| Download interrupted, insufficient space or corrupt installation | Show the reason, amount needed where known, and Retry or Cancel. Inject each failure, retry with valid files, and verify that partial files never appear installed. |
| Microphone denied, disconnected or silent | Offer microphone settings or Record again. Test deny → grant and silence → new take without an app restart. Cancelling removes the draft. |
| Preview or synthesis fails, or an accepted recording is missing | Show Retry, Set up again or Choose a built-in voice as appropriate. Test repair and a subsequent successful read. Preserve the previous accepted voice during a failed replacement. |
| Stop, replacement or deletion races a pending reply | Invalidate the generation, silence output and release private inputs. A late reply cannot restart playback. Test with a deliberately delayed reply followed by a new read. |
