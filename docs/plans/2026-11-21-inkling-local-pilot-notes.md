## Deviations

The plan specified one run manifest. Phase 1 stores the static model/runtime specification in Git and the computed six-row manifest in the ignored preview directory. A pinned digest allows an operator to reproduce the complete preview without tracking a second copy. Only the public tokenizer and configuration metadata were acquired during Phase 1 to verify real tokenization without acquiring weights. Runtime dependency locking, original-weight compatibility, actual device memory, sentence latency and human quality judgments belong to the measured phases.
