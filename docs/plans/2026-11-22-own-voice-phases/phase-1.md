# Package a local voice engine

Build the candidate as a private arm64 helper in the existing macOS app. Pin the SDK, transitive dependencies and public model manifest to the versions that pass the [native feasibility test](../../research/2026-11-22-own-voice-native-feasibility.md). Include its licenses and compiled shader resources, sign nested code before signing the host, and use the normal hardened runtime configuration. Identify third-party binaries, notices and redistribution terms before distribution. Keep the main app universal. Launch the helper only on a personal-voice operation and reuse it across the sentences of an active reading. Do not launch a process for each sentence. A stock-only run must never launch it or map model weights.

Use a private parent–child IPC channel. Pass bounded request data and PCM through that channel. Keep user text, transcripts, recordings and paths out of process arguments, environment, crash descriptions and standard logs. Audit the SDK's own prints. Keep the helper's diagnostics content-free. Separate model preparation from conditioning on a particular recording. Precompute or reuse conditioning in memory while that profile is active. Release it when changing or removing the profile, ending the session or quitting the app.

Validate the pinned model tree and file types before invoking the SDK's local loader, including its speech_tokenizer subdirectory. Run loader-generated tokenizer work only in the model's private staging area. Test a malformed file where a directory is expected and a symlink pointing outside staging. Both must fail safely while retaining the installed model, profile and unrelated files. Disable remote loading at inference. Use distinct test roots for shared downloads and personal profiles.

**Automated acceptance.** Build the assembled Release app with xcodebuild, inspect executable slices and nested signature/entitlements, verify the shader and run outside the source checkout. First prove the offline harness rejects a real network attempt, then generate a new sentence from a synthetic reference. Check 24 kHz mono finite non-silent PCM, check that a separate local recognizer recovers the target, and compare it with the reference transcript. Validate a missing shader, malformed model, cancellation and helper crash. A new session must succeed after the fault is removed. Before building enrollment UI, feed a multi-sentence fixture through one loaded helper and record queue underruns, cumulative generated audio versus elapsed generation and the longest inter-sentence gap. A sustained fixture must keep pace with playback at normal speed. If it cannot, investigate the measured bottleneck before proceeding to enrollment. Record helper bundle size, requested model bytes, cold load, conditioning, first nonempty PCM, full-unit generation, produced duration and peak process memory. Re-run built-in speech with the model absent. Add a network-free verification step using small fixtures and run make verify sequentially.

**Native acceptance.** Run the assembled helper under the project's signing configuration on the Studio. Time-to-PCM measures generation. Shortcut-to-audible-output belongs to Phase 4. Human likeness requires the owner's own enrollment.

**Work split.** [batch-eligible] Package, shaders and signing belong to one owner. The offline runner, synthetic fixture and format checks can be built by a second owner in a disjoint qualification directory using the same fixed sentence. The integration owner runs the end-to-end checks.
